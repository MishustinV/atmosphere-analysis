## О проекте

Система предназначена для приёма, обработки и анализа потоков спутниковых данных о состоянии атмосферы Земли. Каркас включает:

- **Модуль приёма данных** (C++) — парсинг потоков спутниковых данных.
- **Модуль анализа** (C++) — расчёт показателей состояния атмосферы.
- **Модуль визуализации** (C#) — отображение результатов.

## Технологии

- **C++** (стандарт C++17) — обработка данных.
- **C#** (.NET 8) — визуализация и интерфейс.

## Структура проекта

```
atmosphere-analysis/

├── docs/         ← документация

```

## Сборка

### C++

```bash
cd cpp
g++ -std=c++17 -Iinclude -o app src/*.cpp
./app
```

### C#

```bash
cd csharp
dotnet build
```
